# Vanta’s Xbox Ports

Unofficial Xbox Developer Mode ports of FNAF World, The Joy of Creation: Story Mode, JR’s and Night Blights, by Vanta. SK8 is coming soon.

- **Website and install guide:** https://vanta-xbox-ports.pages.dev/
- **Downloads (.appx):** [Releases](https://github.com/0gjfc/vanta-xbox-ports/releases)
- **Bug reports and port requests:** [Issues](https://github.com/0gjfc/vanta-xbox-ports/issues)

Install the .appx files on an Xbox in Developer Mode with Device Portal (**My games & apps → Add**). The website has the full step-by-step guide.

Every game belongs to its creators: Scott Cawthon, Nikson, Ramenov & Darroc, and Hot Cross Games & Trapdoor Games. Not affiliated with Microsoft or Xbox.
